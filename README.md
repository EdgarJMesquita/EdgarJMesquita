# About Me

Hey, my name is Edgar — I'm a **mobile developer** with over 4 years of experience.

I’ve worked with cross-platform tools like **React Native**, building production apps and reusable libraries.

I’ve also explored **React Native library development**, using **Android Studio** and **Xcode** to write platform-specific code in **Java/Kotlin** and **Objective-C/Swift**.

In late 2024, I shifted my focus to **iOS development** using **Swift** and **UIKit**, and have built several personal projects to increase my understanding of the iOS ecosystem.
